# Blinkit Clone 🛒

A frontend clone of the Blinkit grocery delivery website built using HTML and CSS.  
This project replicates the UI design of Blinkit's homepage including navigation bar, product sections, and responsive layout.

## 🚀 Features

- Responsive Navbar
- Hero Section
- Product Categories Section
- Grocery Product Cards
- Clean and Modern UI
- Mobile Responsive Design

## 🛠️ Technologies Used

- HTML5
- CSS3
- Media Queries

## 📂 Project Structure

- blinkit.html – Main homepage
- blinkit.css – Styling file
- media.css – Responsive styling
- .hintrc – Lint configuration
